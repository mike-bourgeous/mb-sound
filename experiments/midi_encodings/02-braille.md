# MIDI as text: Braille bytes

One character per byte: byte `b` becomes U+2800+b in the Unicode Braille Patterns block, which has exactly 256 characters.  The eight dots map to the eight bits, so it is in a sense a "visual binary" encoding.  Newlines every 64 characters are not data.

Source: `Synth Demo 1.mid` by Mike Bourgeous (4411 bytes, format 1, 4 tracks, 960 ticks per quarter note).  This encoding: 13302 bytes of UTF-8, 4480 characters.
