# Plan layer (fused regions)

Detailed notes moved from CLAUDE.md (2026-10-10); CLAUDE.md keeps a summary and points here.  Update both when behavior changes.


`lib/mb/sound/plan.rb` (+ `plan/`; executor `ext/mb/sound/fast_plan`) runs connected regions of a graph as one op list per block in C (optimizer stage 4, P1, 2026-10-08), an as-if transformation: the same samples (every op bit-exact with its node, except the default fast sines within -124 dB, see below; Numo's own FMA caveat for complex×complex products as in fast_arithmetic), the user's graph untouched (plans reference nodes; graphviz, `sources`, names unchanged), and node state in the nodes (Tone::State's Arrays), so a plan can drop at any block boundary.
- Automatic: `Synth` installs a plan per lane and `Session#add` per player (`Plan.install`, which also precompiles).  `MB_SOUND_PLAN=0` turns plans off, `=ruby` runs the Ruby mirror; `MB_SOUND_PLAN_CHECK=1` (or `warn`) runs every planned block both planned and unfused on the same inputs and states and compares samples and node states (`Plan.check`: raise in scripts and specs; `:warn` disables that region).
- Node protocol (`Plan::Describable`, which prepends the `Plan::Planned` hook): `plan_describe(p)` returns the node's output Value, built with the DSL (`Plan::Builder`): `p[handle]` (described in the same plan if the region owns that node, else a boundary input), `p.const`, Value operators (`* + / ** real imag`), `p.tone(...)`, `p.param(constant)`, `p.boundary(h, optional:)`; plus `plan_inputs`, `plan_boundary_inputs`, `plan_unsupported_reason`, `plan_snapshot`/`plan_restore`, `plan_output_type`.  Multiplier's: `@multiplicands.keys.reduce(p.const(@constant, complex: plan_complex_buffer?)) { |product, m| product * p[m] }`.
- Covered: Constant (live params: steady values filled, changing ones' own buffers), Multiplier, Mixer, ComplexNode `:real`/`:imag`, `GraphNode#/` and `#**` and `Tuning#freq` (`ProcNode#plan_operator`; the tuning is read as each block runs), Shaper on real inputs (`include/mb_clip_shape.h`, shared with FastClip.shape), and Tone on the `:naive` and `:synth` kernels (every naive shape and noise, PolyBLEP shapes, pwm, LFO fades) with frequency, phase modulation, width, gain, and reset inputs (targets, `rnd`) as `Op::Tone`: split at reset samples, kernels shared with fast_sound/fast_synth through `include/mb_osc_shapes.h` and `include/mb_bl_osc.h`, each jump through the Tone's own Ruby (`Tone#plan_reset`; key sync costs what it costs unplanned, no fallback).
- Covered since P2 (2026-10-09): Notes event nodes (Gate, Number, Velocity, Lift, Trigger, KeyTrigger, Choke, EnvelopeInputs and its Ports, Glide, FadeIn with a numeric delay, PolyPressure, and the smoothed controllers Control/Bend/Pressure), Aftertouch (`Op::Max`), Notes::Frequency (Adds, NoteFreq on `Plan::CURRENT_TUNING`, `Op::Keep` of `#value`), NoteEnvelope::GmTime, and Envelope/NoteEnvelope (`Op::Envelope`: FastEnvelope's kernel moved into `include/mb_envelope.h`, on the envelope's state NArray, with its idle skip).  Boundaries for now: curve shapers, delays, SampleHold, TempoNodes, tones with sync, ports, timelines, feedback, BLIT, clean resets, or wavetables.
- Covered since P3a (2026-10-10, branch plan-p3a): filters (`Filter::SampleWrapper` with an SVF → `Op::FilterSvf`, with a `structure: :biquad` Cookbook → `Op::FilterBiquad`; `GraphNode::FourPole` in every mode, drive mode, clip, curve, self-oscillation, and the diode ladder → `Op::FourPole`; `lib/mb/sound/plan/filter_ops.rb`, C in `fast_plan/plan_filters.c` and `plan_biquad.c` sharing `include/mb_svf.h`, `mb_four_pole.h`, `mb_biquad.h` with fast_filter and fast_sound; the filter's own state and settings read each block, its remembered parameters written back; four-pole node parameters that end replay the block unfused, as envelope inputs), Notes::Cutoff/Quality/Resonance (`Op::Exp`, `Op::Clip`, Numo's float semantics), SQ80::TimeScale (`Op::TimeScale`).  `0 * x` folds to 0 (`Plan::Fold`, `Op::ZeroFold`; user decision 2026-10-09): a product with a zero constant of the patch (a Const, a fill, or a folded product; never a Constant node's live value) fills 0, x's ops still run every block (state, Tees, and envelopes stay in step), a non-finite x gives 0 where unfused gives NaN; warned once per kind (`Plan.fold_warnings`, `MB_SOUND_PLAN_FOLD_WARN=0`) and listed by `Plan.explain`.  Vectorized 2^x under `:fast` (user decision 2026-10-09; `include/mb_vec_exp2.h`, mirror `Plan::VecExp2`): NoteFreq and Pow with a Constant base (`OP_POWF`), 4.6/5.1 ns per sample against libm's 16, counted within `VecExp2::TOLERANCE` (2.4e-7 of the level; no float differing from libm was found), out-of-range and NaN samples recomputed with libm.  Envelope parameters filled with a constant go to the kernel as numbers, so its runs apply (see Envelopes).  Measured (graph_profile, YJIT, best of 3 alternating with master-ai b7fd18e5 while a Valgrind run used one core; % of realtime at 128/512, master → P3a; c_major.mid / dense_modulated.mid): fm_bass 14.5→13.5 / 10.2→8.8 and 23.6→22.2 / 19.7→18.0; fm_epiano 7.3→7.0 / 3.3→3.0 and 15.0→14.1 / 9.3→8.7; sq80_voice 72.3→59.7 / 28.0→25.6 and 87.1→76.3 / 42.4→38.1; stereo_drone 29.8→25.4 / 27.3→23.7; pluck 93.0→30.2 / 53.4→12.5 and 117.4→35.4 / 66.8→18.2; feedback_song 110.4→35.9 / 60.5→14.6; flanger 19.4→16.2 / 16.2→13.3; tape_delay 7.8→7.9 / 6.7→6.7.  Still boundaries in sq80_voice: wavetable KeyedTones, SampleHold, and the Tee branches around them.
- Shared inputs (`Plan::SharedInputs`, 2026-10-09): a Synth samples each controller read by the regions of several lanes (every branch of the node's Tee a region boundary input; lanes without resamplers; a lane's own nodes stay with the lane, which advances them itself while skipped) once per block in `#sample_lanes` and hands the buffer to every region (`Region#gather`), skipping ~100 Tee branch reads per fm_bass buffer; regions running unfused replay it, and a mid-block rebuild or disabled region puts it on every branch (`#guard!`) so no source advances twice.  Measured (alternating with master-ai, best of 3, % of realtime at 128/512): fm_bass c_major 14.7→14.7 / 10.0→10.0, dense 23.6→22.9 / 19.2→19.2; fm_epiano c_major 7.4→7.4 / 3.5→3.5, dense 15.4→14.9 / 9.4→9.3 (a branch read cost ~0.1-0.25 us).
- Event-driven nodes (`Plan::EventList`, `lib/mb/sound/plan/events.rb`): each block the Region runs the node's *feed* in Ruby (`#plan_feed`, after the boundary inputs are read): its own event handling (reader, NoteStack, chases, `#render` with the exact-sample edge rules, through `Plan::Recorder` standing in for the buffer) records an EventList (held values from an offset, impulses, Glide smoothstep ramps, FadeIn ramps, or rendered curve samples), and `Op::Events` renders it in C.  Node state stays in the node, so plans still drop at any block boundary.  `Notes::FeedGroup` reads a region's nodes on one stream once per block; `#plan_relevant?` skips events that can't change a node (not for Glide/FadeIn: events split their ramps).  Smoothed controllers add `Op::Smooth` (`include/mb_smooth.h`, shared with FastControl; the feed copies the block's jumps).  Feeders whose stream is over or ends within the block (`#plan_finished?(count)`) run that block unfused and become boundaries (check mode can't replay a stream's end); when the stream's content jumps back (restart, seek, rewind: `#plan_generation` changes), the first such node to be sampled re-includes every one of them at once, plus nodes found unsupported meanwhile (`Plan::RestartWatch`, `Installation#reinclude`; user: "do what makes most sense live", 2026-10-09).  Planning is opt-in per class (`plan_events!`); `Describable` prepends `Planned` to subclasses too (NoteEnvelope's own `#sample` must not run before a region it roots).  Envelope inputs outside the region are optional boundaries: an ending one replays the block unfused (`#plan_input_ended` returns `:replay`) and is a constant afterwards; Synth's skipped lanes advance fused nodes with `Notes::Node#advance`.
- Ops are Ruby objects (`Plan::Op::*`: a dst Value, operands, the describing node, `#run_ruby` mirror, `#exact?`); `Plan::Program` lists them (`to_s`), allocates registers (linear scan; a dst never shares its operands' slots; params own theirs), and lowers them to Int32 words for `FastPlan.run`.  `Plan.explain(graph)` lists regions, ops, and why other nodes stay unfused.
- Region finder (`Plan::Installation`): consumers first; a describable node joins its readers' region only if all of its readers, through every Tee branch, are fusable inputs of that one region, else it roots its own region (regions under `Plan.min_nodes`, 2, are dropped).  Regions read boundary inputs through their nodes' own Tee branches (lockstep kept); optional inputs (reset triggers) may end; a buffer of another type replays the block unfused (`Tee::Branch#replay`) and recompiles.  `Plan.changed(node)` after structural edits (Multiplier#add, a new Mixer summand, Tee branches, Tone configuration, spies) rebuilds the installation before its next block; `structure: false` (sample rates, constants, existing gains) recompiles the region.  Introspection never misses a buffer: spied nodes and `Plan.observe(node)` stay boundaries, and a fused node read from outside its plan replans (`Region#foreign_read`).
- `Plan.precision` is `:fast` by default (user decision 2026-10-09; `MB_SOUND_PLAN_PRECISION=exact` or `:exact` for bit-exact plans): naive real sines without noise run a vectorized float polynomial (`include/mb_vec_sine.h`: the naive kernel's exact phases, then a branch-free shape pass GCC vectorizes at baseline flags; Ruby mirror `Plan::VecSine`, bit-identical), within 6e-7 of libm (-124 dB); `Op::Tone::FAST_TOLERANCE` 4e-6 per block in check mode (a fast modulator's error moves the phases it modulates), node states compared within `Region::STATE_TOLERANCE` (1e-5, `Plan.states_close?`) for inexact programs, `plan_compare` within -100 dB of the peak.  Complex sines are exact (the old scalar fast path, `mb_fast_math.h`/`FastMath`, is gone).  `mb_wrap` floors without libm (`mb_floor` in `mb_ext_helpers.h`, bit-exact; naive sines ~10% and ramps ~27% cheaper).
- Specs: `spec/lib/mb/sound/plan/` (`plan_compare` in `spec/support/plan_helpers.rb` runs a graph unplanned, in C, and with the mirror over 21 block sizes from 1 to 800 with events, bit for bit for exact programs; mirror tones within 1e-6, as the Tone's own Ruby kernels; `notes_ops_spec.rb` also runs every example in check mode, which compares node states after each block) and `spec/ext/mb/sound/fast_plan_spec.rb`; in memcheck with `notes_fast_paths_spec.rb`.  Bit-exact wiring specs (and the Tone null-test references) set `Plan.precision = :exact`.
