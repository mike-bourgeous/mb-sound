# MIDI

Detailed notes moved from CLAUDE.md (2026-10-10); CLAUDE.md keeps a summary and points here.  Update both when behavior changes.


`lib/mb/sound/midi/` is a pull-based event layer, loaded from `midi/streams.rb` after Sequence: Sources make Events, Streams share them among readers, Notes turns them into signal nodes, and Synth allocates voices.  Nothing is pushed through callbacks, and nothing reads a clock except live input.

- `MIDI::Event` (`midi/event.rb`): the only MIDI message type (`Note#to_midi`/`Pitch#to_midi`/`Tone#to_midi` return note-on Events whose `bytes` `MIDI::Output#<<` sends), a Data value (normalized velocity/CC/pressure 0..1, bend -1..1, raw kept, 0-based channel, time in Rational seconds since the stream start; allocator types `:choke`/`:glide` and `legato`).
- Sources (`midi/source.rb`: `read(from, to)`, `seek`, `restart`, `ended?`, `music_end`, `chase`; note-ons/offs kept balanced across jumps): `FileSource` (one tempo via a tempo-map object, `loop:`; `#notes`/`#note_stats` list notes with key and pedal release times as played, via `MIDI::NoteList` in `midi/note_list.rb`, used by `bin/midi/midi_roll.rb`), `ClipSource` (see Sequences), `LiveSource` (below).  `MIDIFile` (`midi/midi_file.rb`) only parses and analyzes files (`events`, `tracks`; no clock).
- `MIDI::Stream` (`midi/stream.rb`) reads a source once for many `reader`s (cursors in seconds, so any sample rate; late readers start at the slowest), stamps bend ranges from RPN 0, and makes transform views (`midi/transform.rb`: `channel` 0-based, `transpose`, `sustain` (the only sustain handling), `velocity_curve`, `bend_range`).  Streams include `Nameable`/`Traversable` but aren't GraphNodes.  `Stream.for` takes a Stream, Source, Input, Clip, MIDIFile, filename, or anything with `#to_midi_stream` (a Notes).
- `MIDI::LiveSource` (`midi/live_source.rb`; `Stream.live(connect:, output:, timing:)`) reads `MIDI::Input#read_raw` (JACK frame times or RtMidi deltas).  `MIDI_TIMING=exact` (default) keeps timestamp spacing at a constant latency L (default: the output's queue limit + period + one buffer, ~63 ms with `:default`, ~18 ms with `:low`; `latency:` overrides); JACK input with a JACK `output:` is sample-exact through `DeviceOutput#jack_clock`, else the input clock is anchored at the first events and re-anchored when off by more than L (`#track_drift` is the hook for a DLL); `asap` puts events at the start of the read.  `MIDI::RealtimeReader` (`midi/realtime_reader.rb`) plays a file or live input against the wall clock for the bin/midi tools (no audio).
- `MB::Sound::Notes` (`lib/mb/sound/notes.rb`, `notes/`): the per-voice (or mono) signal DSL over a stream (`v` in synth code; `Notes.new(stream | source | clip | file, sustain: true)`).  Note nodes read `note_stream`, the input through the sustain pedal transform (lazy and held weakly, so a Notes used only for controllers or as a synth source never holds the input back), unless `sustain: false` (Synth lanes, already pedaled, and `Clip#notes`); `stream` stays the input (controllers, `to_midi_stream`, `.source`); `control_specs` adds the pedals while note nodes use them.  Every node has its own reader and puts events on exact samples at its own rate: `gate`, `trigger` (impulse = velocity), `number`, `velocity`, `lift`, `choke` (`:choke` events, CC 120), `freq` (Tuning + bend); last-note priority; held values chase `Source#chase` after jumps.  Channel-wide nodes (`bend`, `bend_semitones(range)`, `pressure`, `cc(n, range:)`, GM-named `mod`, `brightness`, `resonance`, `attack_time`, `vibrato_rate`, ... with `MIDI::ControlSpec`s, listed by `notes.controls`) are shared per control stream (`Notes.control_stream`).  `env`/`amp_env`/`fm_env`/`filt_env` are `NoteEnvelope`s wired to gate/trigger/velocity/choke (`lift: true` opt-in), GM2 time scaling (CC 73/75/72) unless `.gm(false)`, registered for `notes.idle?`/`notes.level`.  `v.hz` is a `NotePitch` whose tones key-sync (`Notes::KeyedTone`, `reset(v.key_trigger)`) unless `.free`/`.lfo`/`.sync`; `.bend_range(12.st)`, `.transpose`, `.vibrato`, `.glide(50.ms | :gm, legato:)`.  `v.key_trigger` (`Notes::KeyTrigger`, alias `key_sync_trigger`) is `v.trigger` without note-ons that add energy to a sounding voice (user rule, 2026-10-05: adding energy to an existing envelope doesn't reset oscillators), i.e. note-ons while a `retrigger: :add` envelope of the Notes is sounding, decided per buffer from the envelopes' state at the buffer start (`Notes#adding_at?`, `NoteEnvelope#sounding_at?`, so graph order doesn't matter); `v.trigger` fires at every note-on.  `v.cutoff(base, env:, keytrack: 0.5)` and `v.quality(q)` feed `filter(...)`; `v.reso(amount)` (CC 71 around the base) feeds `lp4(resonance:)`.  `v.poly_pressure` (alias `key_pressure`; per-key 0xA0 pressure of the newest held note, 0 at each note-on, held after release; the Allocator routes each key's pressure to its lane), `v.aftertouch` = max(poly, channel pressure) (it was an alias of `pressure`; `channel_pressure` is the new alias); ControlSpec type `:poly_pressure`, listed but left out of ACID XML.  Controller smoothing (2026-10-08; `Notes::Smoother`, kernel `FastControl.smooth`, mirror `Smoother.smooth_ruby`): CCs, GM-named controls, channel/poly pressure, aftertouch, and bend (so `v.hz`/`v.freq`) glide between MIDI steps through a triangle FIR (two moving averages; each step an S-shaped transition that lands exactly after the time, delay half of it): `Notes::CONTROL_SMOOTHING` 10 ms, `BEND_SMOOTHING` 5 ms (`Notes.control_smoothing`/`.bend_smoothing` apply live: nodes made with the default keep a smoother, a pass-through one while the default is false, and `Smoother#length=` re-plans it from the current output on its next buffer, also in plans (the plan op reads the smoother's arrays each block); nodes given `smooth:` keep theirs; spec_helper restores them); adaptive smoothing `smooth: :adaptive` (`Notes::ADAPTIVE_SMOOTHING` 5..200 ms) or a Range of times (also as the global defaults): each step glides linearly from the current output over the time since the previous step, clamped (the user's scroll-bar idea; a slow 7-bit wheel becomes a line, lag one step interval; kernel `FastControl.adaptive`/`mb_adaptive_run`, mirror `Smoother.adaptive_ruby`, plan `Op::Smooth` picks the kernel by the state's length, 8 = adaptive); per node `smooth:` (`v.cc(1, smooth: 20.ms)`, `v.mod(smooth: false)`, `v.bend(smooth: 0)`, `p.midi_cc(..., smooth:)`); switch CCs (curve `:switch`) step unless given a time; gate/trigger/number/velocity/lift/choke never smooth; poly pressure jumps at note-ons and content jumps.  Measured on 7-bit pressure steps every 4 ms: energy above 200 Hz / 2 kHz -54 / -65 dB stepped, -86 / -136 at 10 ms (one-pole and linear ramps measured worse above 2 kHz); ~1 us per moving 128-sample buffer, settled buffers pass the frozen constant through (`spec/lib/mb/sound/notes_smoothing_spec.rb`).  Specs that check values on event samples set the defaults to false.  `v.lfo(rate, shape: :tri/:saw/:square/:sine/:noise, depth:, delay:, from:, sync: :key/:free/:random, wheel:, pressure:, unipolar:, human:, seed:)` (a Multiplier of a `Tone#lfo`, depth, and FadeIn; Duration rates follow the tempo; `:noise` is `GraphNode#sample_hold` (alias `sah`) on a naive square; `vibrato` is built on it).  Mod sums (`ModMethods`, also `MB::Sound.mod_sum`): `v.mod_sum(base, src => amount)` (Intervals in semitones) and `v.mod_scale(base, src => amount)` (base × 2 ** octaves); Symbol sources in voices: `:velocity`, `:vel_x`, `:key` (octaves from C4), `:wheel`, `:pedal`, `:breath`, `:bend`, `:pressure`, `:poly_pressure`, `:aftertouch`, `:lift`, `:gate`.  Demo: `bin/synths/sq80_voice.rb` (~50% of realtime at 128-sample buffers and ~16% at 512 for 8 voices without its chop/flutter oddities, ~80%/26% with them, normalized to the fm_bass reference below, 2026-10-07).  Gate/trigger/choke and envelopes return nil once the stream ended and the envelopes are idle; nodes report `ended?` for script ringdowns.  Nodes are cached per instance through WeakRefs.  Fast paths (`Notes.fast_paths`, `MB_SOUND_NOTES_FAST=0` off; null-tested in `spec/lib/mb/sound/notes_fast_paths_spec.rb`): constant frozen buffers while nothing changes (consumers cache by identity), one `Notes::EnvelopeInputs` reader per envelope, idle envelope kernel skips, shared Stream events and Frequency nodes.
- `MIDI::Allocator` (`midi/allocator.rb`) splits a stream's notes into `lanes` (`Lane < Stream`, `voices + spares`; one in mono mode), each with at most one note plus every channel-wide event, reading its input once so lanes read in any order with identical results.  When full, the `steal:` chain (`:same_note`, `:oldest_released`, `:oldest`, optional `:quietest`; `protect: :lowest/:highest`) chokes a victim while the new note goes to a spare.  `lane.idle_check` frees released lanes.  `retrigger:` (when every voice is busy and the chain has `:same_note`): `:reuse` (default: restart the newest lane playing the note), `:louder` (reuse it only if no envelope would attack downward, via `Lane#louder_check`/`level_check`; else as `:new_voice`), `:new_voice` (a spare takes it, so the old note rings on), `:quietest` (the quietest lane playing the note), `:per_key` (one lane per key, always restarted, even with voices free).  Mono (`voices: 1`, `priority: :last/:low/:high`) sends legato note-ons; polyphonic `glide_mode: :last` (default) sends `:glide` events, `:voice` none.  Unison isn't built.
- `MB::Sound::Synth` (`lib/mb/sound/synth.rb`; `MB::Sound.synth(source = nil, voices: 8, **opts) { |v, i| }`, nil meaning live `midi`; `notes.synth`, `clip.synth`): `Synth.new(source, voices: 8, spares: 2, steal:, protect:, mono:, priority:, glide_mode:, retrigger:, controls: [], bend_range: nil, sustain: true, seed: nil, tail: 11, skip_idle: true) { |v, i| graph }` reads the source through `.sustain`, splits it with an Allocator, calls the block per lane with a Notes on it, and sums the lanes (`sample_individual(count)`; bundles give one `Synth::Output` per channel).  Lane blocks run in `MB::Sound.with_seed(seed + i)`.  `controls: [:volume, :expression, :pan]` (CC 7/11/10) are opt-in.  `retrigger:` takes the Allocator modes plus `:add` (reuse, every lane envelope `retrigger: :add`) and the presets (`Synth::RETRIGGER_PRESETS`): `:string` (`:per_key` lanes + `:add` envelopes, never doubling a key; user-approved for pianos/e-pianos; key-synced oscillators keep their phase on these re-strikes, `.free` ones never reset; see `bin/synths/fm_epiano.rb`) and `:ring` (alias `:bell`; user's choice for bells, fm_bell's default with `-r` to compare): a free voice if any, else the quietest lane ringing the note with `:add` envelopes, else steal the quietest (`RING_STEAL` unless `steal:` given).  Renders: /app/tmp/listening/retrigger/.  `ended?` = finite source over and every lane idle: Notes idle and the lane's output, measured after each buffer, under -90 dB (`Synth::QUIET`, `Notes#quiet_check`, `Synth#quiet_lanes`), so envelope-less voices (filter pings) and resonant tails ring out and aren't reused while ringing (the peak is also `Notes#level` for `steal: :quietest`); the runner's ringdown keeps a Synth and ignores the nodes inside it; then `tail:` seconds of silence and nil.  `skip_idle: true` skips idle lanes (Notes idle, output under -120 dB, no delays/reverbs/FIR/feedback loops/tempo nodes inside the lane; MIDI transforms and clip sources upstream only make events, which wake lanes, so clip synths skip too since 2026-10-10; not sample-exact).  Cost (2026-10-04, YJIT, 8 voices, saw × amp_env → lowpass): ~6% of realtime at 128-sample buffers, ~2.3% at 512.
- MIDI transforms (`midi/stream_transforms.rb`, `midi/transform/*.rb`; user decisions 2026-10-09 in the memory's ideas-midi): Stream methods mirrored on Notes (a Notes with the same pedal setting; pedals hold transformed notes) and, for `echo`/`arp`/`strum`/`chord`/`snap`/`through`, on Clips (returning Streams).  Future-event transforms are `Transform::Scheduled` (a time-sorted queue sent as it comes due, so any read size gives the same events; a ledger of note ids keeps output balanced through jumps, swaps, and stream ends: `overlap: :retrigger` (default; newest note owns the key) or `:stack`, `jump: :ring` (default; queued echoes ring on) or `:cut`) and `Transform::Timeline` TimelineNodes (Stream#sources lists them, so Sessions hand them the transport and timeline).  `echo(delay, count, pitch: degrees/Interval/Array cycled, velocity:, gate: (nil = played length), dry:, scale:, root:) { |e, i| }`; `arp(mode, rate = 16, octaves:, step:, gate: 0.5, velocity: nil/number/accents, swing:, latch:, start: :grid (timeline-locked, waits for the next step) / :key (Juno), steps: [offsets], scale:, seed:)` (modes up down updown downup up_down down_up played random converge diverge pinky thumb chord); `chord(:min7 | degrees, scale:)`, `strum(spread, :down/:up/:alternate/:random/:played, window:)` (live chords need a window, added as latency), `humanize(time, velocity:, seed:)` and `quantize(grid, amount:, window:)` (later only), `snap(scale, root)`, `transpose(step, scale:)`, `select`/`reject`/`velocities(range)`/`map_notes { |e| }` (note-offs follow; `Transform::NoteMap`), `rechannel`, `split(note)`, `merge(*streams)`, `vel`, `velocity_curve(Range)`, `note_length`/`len`, `shift`.  `Event#transpose(step, scale:)`, `#with_channel`.  Random ones seed from `MB::Sound.next_seed` (or `seed:`), one Random per decision from seed + counter.  Unattached chains (`Transform::Spec`): console `echo(...)`, `arp(...)`, `strum(...)`, `chord(...)`, chained by the same names, applied with `stream.through(fx)` or `clip.bake(fx)` (no `>>`).  `Stream#notes`, `Stream#synth`.  Demo: `bin/songs/midi_transforms_song.rb` (header snippets for live keys); renders and bench set in `/app/tmp/listening/midi_transforms/` (`mt_*`).  Not built: live transform slots/`swap :fx`, CC/sequence params (proposal §3.3), record/looper, ratchet/euclid gating of live input, MIDI output scheduling.
- Console: `midi(connect = nil, sustain: true)` is a `Notes` (pedals applied; `sustain: false` gives another Notes on the same input) on a cached `Stream.live` following the background session's output (`midi_stream` gives the Stream, `close_midi` closes them; opening it may switch to the `:low` profile, see Audio I/O); `midi_file(path, loop: false, sustain: true) { |midi| }` is a Notes on a FileSource.

Live MIDI goes through JACK MIDI ports on the shared JACK client when a JACK server answers (see Audio I/O; `connections` are the port's live JACK connections), else the bundled RtMidi 6.0.0 (`ext/mb/sound/fast_midi/`, `MB::Sound::FastMIDI`; CoreMIDI on macOS, ALSA sequencer on Linux): `MB::Sound::MIDI::Input` (`lib/mb/sound/midi/input.rb`) polls the queue in `#read_raw` (once per buffer, from LiveSource).  By default it opens a port named after the script (`DeviceOutput.client_name`); `connect:`/`MIDI_DEVICE` connect to a source by part of its name, searching the other compiled API too when `MIDI_API` isn't set (`Input.find_port`; no match warns with the source list and leaves the port unconnected); `Input.open_live` prints where to connect (bin/midi tools).  `MIDI_API` picks `core`/`alsa`/`jack` (JACK by default when a JACK server answers, jackd or PipeWire's: `DeviceOutput.jack_running?` is `FastAudio.jack_server?`, which dlopens libjack and opens and closes a client without starting a server, ~5 ms).  `MB::Sound::MIDI::Output` (`lib/mb/sound/midi/output.rb`) is a minimal output (`write`/`<<` of bytes, `connect:`), used by `bin/midi/midi_events.rb --forward` and the specs; scheduled MIDI output isn't built.  RtMidi's C API leaves `msg` dangling after errors, so `fast_midi.c` never reads it.  `bin/midi_check.rb` shows the MIDI APIs, why one is chosen, the loaded libjack, audio backends, all ports, and `--listen`/`--loopback` tests (`spec/bin/midi_check_spec.rb`).  RtMidi is vendored unmodified (built with `HAVE_SEMAPHORE` on Linux, as RtMidi's own build does; without it closing a JACK output raced its process callback and crashed libjack under load); `ext/mb/sound/fast_midi/README.md` has the update steps.

Specs send real messages through a private JACK dummy server (`spec/support/jack_dummy.rb`; they skip without `jackd`) with `MIDI::Output`/`FastMIDI::Output`.  Every JACK2 server maps ~38-40 MB of `/dev/shm`, so Docker's 64 MB holds one: spec processes take turns through a lock file (`/dev/shm/mbspec-jackd-UID.lock`); `JackDummy.start` also cleans up after crashed or dead spec servers (registry slots, metadata DB, orphans), and servers run under `setpriv --pdeathsig TERM`.  A spec process from an older checkout (no lock) running at the same time can still crash both servers (SIGBUS; `JackDummy.stop` warns).

`MIDI::ControlMap` (`midi/control_map.rb`) lists the controllers something responds to and writes controller maps for the ACID DAW (user: ACID remote control of synths matters).  It collects `ControlSpec`s from specs, Arrays, other maps, anything with `#control_specs` (`Notes`: the controller nodes in use on its control stream; `Synth`: its lanes' shared controllers, output controls, and the sustain pedals' CC 64/66/67 (`Transform::Sustain::CONTROL_SPECS`) unless `sustain: false`; `Notes::Control` nodes), and graph nodes/bundles (every upstream node with `#control_specs`); equal specs once, specs sharing a CC number grouped.  `ControlSpec#type` is `:cc`, `:bend` (`ControlSpec.bend(range:)`, raw 0..16383 centered at 8192), or `:pressure` (`ControlSpec.pressure`); `Notes#bend`/`bend_semitones` (so every `v.hz`/`v.freq`) and `#pressure` carry them, sorted after the CCs (`ControlSpec#key`; `map[:bend]`, `map.types`).  Enumerable over specs, `numbers`, `[]`, `groups`, `to_s` (also `pretty_print`, for Pry), `to_acid_xml(name: script)`, `write_acid_xml(path)`.  Console: `midi.controls`, `synth.controls` (`Synth#output_controls` is the `controls:` list).  The XML matches the old Manager's byte for byte (`spec/test_data/acid_xml_reference.xml`, `spec/test_data/acid_xml_bend_reference.xml`), except that entries are sorted by CC number and `params=` counts entries.  Effect and synth scripts list their controls (`p.midi_cc` specs, even when constants, the script's MIDI controllers, and the graph's) after the parameters when MIDI is in use, hidden by `-q`, and take `--acid-xml FILE` (`-` prints it; written even with `-q`).
