# Tweening curves

Detailed notes moved from CLAUDE.md (2026-10-10); CLAUDE.md keeps a summary and points here.  Update both when behavior changes.


`MB::Sound::Curve` (`lib/mb/sound/curve.rb`, `curve/library.rb`) maps progress 0..1 to 0..1 (overshoot allowed), shared by glides, tweens, smoothing, shapers, and TimelineInterpolator blends: `Curve[:elastic, overshoot: 0.4, cycles: 4]`, names `linear smoothstep(:smooth,:s) smootherstep sine(_in/_out) quad..quint exp back anticipate elastic squiggle bounce steps ease(_in/_out/_in_out)`, any name with `_in/_out/_in_out/_out_in`, `Curve.db(d)`/`Curve.s(d)` (Envelope's signed-dB curve and :s shape, specs check they match), `Curve.power`, `Curve.bezier`, Procs; `reverse`, `in`/`out`/`in_out`, `>>`, `blend`, `steps`.  `#call` and `#map` (Numo) give identical values; `#lookup` evaluates a 2048-cell Hermite value table in C (`FastClip.curve_lookup`, ~4 us per 512 positions for any curve, within 1e-7 of `#map` except at bounce contacts (1e-4) and vertical end slopes), used by glides.  `bin/plot_curves.rb` plots or tabulates them.

- Glides: `v.hz.glide(t, shape: :squiggle, overshoot:, cycles:)` (`Notes::Glide`; no shape = the old smoothstep code, bit-identical, pinned by `spec/lib/mb/sound/tween_reference_spec.rb`); `swarm(..., shape:, cycles:)` takes per-copy values (`channels(:squiggle, :elastic)`, Ranges).  Shaped glides cost the same as plain ones.
- Tweens: `tween([300.hz, 3000.hz, 800.hz], 1.bar, curve: :elastic)` (`SequenceMethods#tween`, built on `Clip#tween`, a shaped Glide on a clip shifted to keyframes): values are keyframes (each value at its step start, tweening to the next during the step; the last holds or loops back over the last step; repeat a value to hold it); Pitches tween in octaves and give Hz (overshoots stay above 0 Hz), plain numbers linearly, `log:` overrides, mixing raises.  `smooth(t, curve:)` curves every step change (an elastic knob).
- Shaper: `sig.ease(curve, in:, out:, range:, edges: :clamp/:extend/:wrap/:mirror/:none, symmetric:)` (`GraphNode::CurveShaper`; "ease" since `curve`/`shape` are Envelope settings) is antialiased like softclip (ADAA on the excess over the in->out line plus the half-sample allpass; edge modes integrated too; closed forms for polynomial/cosine/exp curves, a Hermite antiderivative table otherwise; `FastClip.shape_curve`, mirror `CurveShaper.shape_ruby`); `aease` is exact for control signals.  Demo: `bin/songs/tween_song.rb`; renders in /app/tmp/listening/tweening/.

- Bounce rhythms: `bounce_hits(2.bars, count: 16, elasticity: 0.75, note: C2, reverse:)` (`SequenceMethods`) is a Clip of hits at length × (1 - e^i), converging on the bar line; velocities fall by `decay:` separately from the timing (`:gentle` e^(i/2), default since 2026-10-08 (user's listening pick); `:speed` e^i, the impact speed, the old default; `:none`; a factor per hit; a Curve or Curve name over the hits; a Proc of (i, position fraction)), and `pitch: -1` (semitones or Interval per hit, or a Proc) moves later hits; demo `bin/songs/bouncing_ball.rb` (per-section decays: 0.9 per hit for the drop and settle, the user's picks; `--decay` overrides all; balls loop with `align: :launch` so they drop where launched).
- Dynamic cookbook cutoffs (`filter(:lowpass, cutoff: node)`) clamp to `Cookbook::DYNAMIC_MIN_CUTOFF` (1 Hz, like FourPole; negative and NaN included).  Fast moves into very low cutoffs still make a direct-form biquad's output jump (a DC bump that decays once the cutoff rises; measured in the commit 8323e7d1 message), so tween cutoffs as Pitches.
