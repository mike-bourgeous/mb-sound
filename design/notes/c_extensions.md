# C Extensions (compiled via rake-compiler)

Detailed notes moved from CLAUDE.md (2026-10-10); CLAUDE.md keeps a summary and points here.  Update both when behavior changes.


- `ext/mb/fast_sound/` - Fast waveform generation (its cookbook biquad in `include/mb_biquad.h`, shared with fast_plan) → `lib/mb/fast_sound.so`
- `ext/mb/sound/fast_resample/` - libsamplerate bindings → `lib/mb/sound/fast_resample.so`
- `ext/mb/sound/fast_wavetable/` - Band-limited wavetable kernels (`FastWavetable.oscillate`, `.sync`, `.lookup`, `.play`; see Wavetables; the table readers, interpolation, warp corners, and the cycle-mode oscillator loop are in `include/mb_wavetable.h`, shared with fast_plan) → `lib/mb/sound/fast_wavetable.so`
- `ext/mb/sound/fast_delay/` - Delay line read/feedback kernels (`DelayLine`; interpolation in `include/mb_delay_interp.h`, shared with fast_loop) → `lib/mb/sound/fast_delay.so`
- `ext/mb/sound/fast_synth/` - Band-limited oscillators (`FastSynth.oscillate_bl`, `.blit`, `.oscillate_sync`) and the feedback sine (`.feedback_sine`) → `lib/mb/sound/fast_synth.so`
- `ext/mb/sound/fast_clip/` - Antialiased waveshapers (`FastClip.shape`) → `lib/mb/sound/fast_clip.so`
- `ext/mb/sound/fast_unison/` - Unison copy frequencies for detune nodes (`FastUnison.exact`/`.interp`/`.scale`; built with `-ffp-contract=off`, mirror `Unison::Detune::RubyKernel`) → `lib/mb/sound/fast_unison.so`
- `ext/mb/sound/fast_arithmetic/` - Allocation-free kernels mirroring Numo exactly (`-ffp-contract=off`; complex products only with one truly complex factor, so Numo's own FMA contraction can't make them differ): Multiplier/Mixer (`product`/`mix`), `divide`/`power`, `min_max`, `wet_dry` (Filter::Delay, Reverb), `copy`, `circular_read`/`circular_write` (MB::M's ring copies), `complex_part` → `lib/mb/sound/fast_arithmetic.so`
- `ext/mb/sound/fast_envelope/` - Envelope state machine (`FastEnvelope.process`, kernel in `include/mb_envelope.h`; built with `-ffp-contract=off` for its exact mirror) → `lib/mb/sound/fast_envelope.so`
- `ext/mb/sound/fast_control/` - Control-signal kernels: the MIDI controller smoother (`FastControl.smooth`, kernel in `include/mb_smooth.h`, mirror `Notes::Smoother.smooth_ruby`) → `lib/mb/sound/fast_control.so`
- `ext/mb/sound/fast_audio/` - Sound card I/O through bundled miniaudio, plus the JACK backend (see Audio I/O) → `lib/mb/sound/fast_audio.so`
- `ext/mb/sound/fast_midi/` - Bundled RtMidi (see MIDI) → `lib/mb/sound/fast_midi.so`
- `ext/mb/sound/fast_resonator/` - Struck resonator (`FastResonator.ping`, mirror `Resonator.process_ruby`; see Drum machines) → `lib/mb/sound/fast_resonator.so`
- `ext/mb/sound/fast_plan/` - The plan layer's op-list executor (`FastPlan.run`, `.run_lanes` for lane groups, `.enums`; mirror `Plan::Program#run_ruby`; see Plan layer; filter ops and their lane-major kernels in `plan_filters.c` (clang FP_CONTRACT OFF by pragma, matching fast_filter) and `plan_biquad.c` (compiled like fast_sound, whose biquad it shares); wavetable tones in `plan_wavetable.c` (FP_CONTRACT OFF, sharing `mb_wavetable.h` with fast_wavetable)); built with fast_sound's and fast_synth's flags so the oscillator loops it shares with them (`include/mb_osc_shapes.h`, `include/mb_bl_osc.h`) compile alike; also shares `mb_clip_shape.h`, `mb_envelope.h` (fast_envelope), and `mb_smooth.h` (fast_control), and has `mb_vec_sine.h`; `mb_envelope.h` and `mb_vec_sine.h` turn clang's FP contraction off by pragma in each function (fast_plan has no -ffp-contract flag; GCC's -std=c99 doesn't contract), and `mb_smooth.h` has no products → `lib/mb/sound/fast_plan.so`
- `ext/mb/sound/fast_loop/` - Feedback loop programs run per sample (`FastLoop.run`, `.constants`; mirror `Plan::Loop::Program#run_ruby`; see Feedback loops; `loop_pitch.c`: `FastLoop.pitch_track`, the pitch compensation and sustain shelf); shares `mb_clip_shape.h`, `mb_svf.h` (fast_filter's SVF, moved there 2026-10-09), and `mb_delay_interp.h`; built with `-ffp-contract=off` → `lib/mb/sound/fast_loop.so`
- `ext/mb/sound/fast_reverb/` - The reverb network (`FastReverb::Network`: diffusion stages a block at a time, the feedback delay network per sample, modulated reads, loop processing, ducking/gate; mirror `Reverb::Network::RubyKernel`; see Reverbs); built with `-ffp-contract=off` → `lib/mb/sound/fast_reverb.so`
- `ext/mb/sound/fast_loudness/` - BS.1770 true-peak interpolation for any polyphase filter (`FastLoudness.true_peak(ext, n, phases)`, mirror `Loudness::TruePeak.oversampled_max_ruby`) → `lib/mb/sound/fast_loudness.so`
- `ext/mb/sound/fast_dynamics/` - Dynamics (see Dynamics): `FastDynamics.compand` (detector, transfer-curve segments, log-domain gain smoother with hold and boost times, lookahead, makeup, parallel mix; mirror `GraphNode::Dynamics.process_ruby`), `.limit` (lookahead brickwall with Annex 2 true-peak detection; mirror `Dynamics::Limiter.process_ruby`), `.crossover` (Linkwitz-Riley trees as SVF rows; mirror `Dynamics::Crossover.process_ruby`); built with `-ffp-contract=off` → `lib/mb/sound/fast_dynamics.so`
- `ext/mb/sound/fast_lofi/` - Lo-fi kernels (deliberate aliasing): `FastLofi.decimate` (sample-rate reducer for `GraphNode::Decimator`: a phase-accumulator zero-order hold at a fractional, per-sample rate, optional splitmix64 jitter of each hold period; mirror `Decimator.process_ruby`; `-ffp-contract=off`) → `lib/mb/sound/fast_lofi.so`
- `ext/mb/sound/fast_sampler/` - Sampler voices: `FastSampler.play` (one channel of a `GraphNode::SamplerVoice`: region choice by key/velocity/round robin at each note-on sample, the note's pitch mark read at the note-on, split keyboards (the last region chromatically above the split), speed by key and the voice frequency, one-shot/forward/ping-pong/release loops, reverse, fades, start offsets, a linear declick tail for re-struck notes; reads sample-mode Wavetable levels through `mb_wavetable.h`; writes its output in place; mirror `Sampler::KernelRuby.play`; `-ffp-contract=off`) → `lib/mb/sound/fast_sampler.so`
- `ext/mb/sound/fast_recipe/` - No numeric kernels: `FastRecipe.frame_binding(iseq)`, the Binding of the innermost frame running a block, through the VM's public debug inspector API (`ruby/debug.h`), so graph recipes read build block locals without a TracePoint, which would make YJIT discard all compiled code (`Recipe.trace_locals`; the TracePoint path is its mirror, `Recipe.locals_mode = :trace`) → `lib/mb/sound/fast_recipe.so`

New C code goes in purpose-specific extensions (the user's preference) rather than growing `fast_sound`; helpers shared between them (`mb_wrap`, `mb_ensure_inplace_sfloat`, `mb_read_signal_input` / `struct mb_signal` + `mb_signal_input`/`mb_signal_at`, `mb_finite_entry`, `mb_tan_pade` (libm-independent tan, mirrored by `FourPole.tan`), ...) are `static inline` in `ext/mb/sound/include/mb_ext_helpers.h`, added to the include path by each `extconf.rb`.  Each kernel has an exact Ruby mirror that specs compare sample for sample (keep the operations identical, including float32 reads of signal inputs).  `depend` files list an extension's headers (rake doesn't rebuild on header changes otherwise; `rake depend:check` and `spec/valgrind/memcheck_selection_spec.rb` compare them with the scanned includes); after changing `depend` or removing a source file, `rm -rf tmp/<platform>/<extension>` so the Makefile is regenerated.
