# Sequences

Detailed notes moved from CLAUDE.md (2026-10-10); CLAUDE.md keeps a summary and points here.  Update both when behavior changes.


`lib/mb/sound/sequence/` (`MB::Sound::Sequence`) holds musical sequences: immutable `Clip`s of `Event`s timed in exact Rational whole notes, built with `seq` (e.g. `seq(C4, E4, G4.n4).n8`), `grid` (drum step strings like `'x...x...'`), and note length methods on `Note` (`n1`-`n8`, `n12`-`n128`, `.d`, `.t`, long names).  A clip is just a MIDI source: `clip.stream` is a `MIDI::Stream` of a new `MIDI::ClipSource` (a `TimelineNode`; a new source per call, since each follows its own graph's timeline), and its node methods are the mono (last-note) `Notes` nodes of `clip.notes`: `clip.env`/`amp_env`/`fm_env`/`filt_env` (NoteEnvelopes: `:analog` curves, default 5 ms/0.2/0.7/0.3, Envelope keywords such as `curve:`/`sensitivity:` (velocity range; `velocity:` is the input), GM2 time scaling off unless `gm: true`), `clip.tone`/`hz` (a key-synced NotePitch: `clip.tone.ramp`, `.transpose(7)`), `clip.freq` (Hz node), `clip.period`, `clip.gate`, `clip.trigger`, `clip.number`, `clip.velocity(range:)`; each call makes its own Notes, so share one with `n = clip.notes`.  Edges land on exact samples at the tempo of a shared `Transport` (`bpm 120`); `spec/test_data/clip_node_reference.json` (outputs of the removed `ClipNode` renderers) is the edge reference.  `clip.synth(voices: 2, **synth_options) { |v, i| }` is `Synth.new(clip, voices:, tail: 0)` (`v` is a lane's Notes; returns Channels for multichannel voices).  Non-looping clips end one buffer after their last note-off; NoteEnvelopes end once their stream ended and they are idle; an ended reset input (key sync trigger) only stops resets, so tones ring through releases.  `legato(0.85)` shortens notes without changing the rhythm.  `reverse` (alias `retrograde`) mirrors a clip or reverses a Seq's steps; `permute([2, 0, 1])` / `permute(seed: 3)` (alias `shuffle`) moves notes among the same rhythm, repeatably from the clip's seed.  In a `Session`, looping clips play in phase with the transport timeline (`seek`, `rewind`), so graphs started at different times stay in sync.  `clip.loop(align: :launch)` (`Clip#launch_aligned?`) instead counts cycles from the exact launch time (`Player#launch`, the bar line rather than the floored first sample; `TimelineNode#start_at(launch:)`), or from the swap that brings it in; seeks and rewinds keep that anchor (the loop plays as the timeline loop rotated by the launch time; before the anchor it plays the cycles leading up to it), only a new launch (`bg`, `resume`) moves it, and `:clip` launch points ignore such loops.  `rotate(amount)` moves a clip's events later by a Duration (or signed whole notes), wrapping within its length.  See `bin/songs/sequence_demo.rb`.  Launches, replacements, swaps, and master chain switches land on the sample whose window holds their time (floor, like Notes edges), so a clip launched on a bar line between samples (e.g. 112 BPM) keeps its first note. See `bin/songs/sequence_demo.rb`.

Note marks (`Sequence::NoteMarks` on Note, the same methods on `Seq::Step`, each returning a Step, chaining in any order: `~!A1`, `A1.!.~`, `(!A1).up.n8`): accent `!A1`/`.accent`/`.acc`/`.a!` (Step flag `accented`, velocity `Clip::ACCENT_VELOCITY` 1.0 vs default 0.75; grid `X` sets it too), slide `~A1`/`.slide(overlap)`/`.s!` (flag `slid`; the note sounds `Seq::SLIDE_LEGATO` 1.02 of its last step, overlapping the next so mono voices glide and legato envelopes hold; `legato` transforms leave slides alone), octaves `up(n)`/`dn(n)` (alias `down`)/`oct(n)` defined once on Pitch via `transpose` (also on Steps and Seqs).  `!` is overridden only on Note and Step (audit and guard: `spec/lib/mb/sound/note_negation_spec.rb`; test values that may be Notes with `nil?`, never `!x`); `!A1.n8` is `!(A1.n8)` (seq raises with a hint); `!~A1` is Ruby's not-match operator (write `~!A1`); `-A1`/`+A1` stay undefined (minus is for signal inversion).  `Rest`/`R` (a rest Step) and `Tie`/`T` (holds the previous note one more step, resolved when the Seq builds events; a rest after a rest or at the start; grid `-`).  `Seq#acid(accent: 1.0, normal: 0.6, gate: 0.5, slide: 1.02)` plays a Seq like the 303's sequencer (half-step gates, ties hold, slides overlap, accent/normal velocities; tracked for swaps); `acid(*items, step: 16)` is `seq(...).len(step).acid`.  `Seq#loop` returns a looping Seq, so step transforms (`acid`, `acc`, `len`, ...) work on loops.  Voice helpers: `v.accent(0.8)` (0/1 per note from velocity), `v.accent_sweep(env, resonance:)` (the 303's accent capacitor: lowpass at 2 - 0.8 r Hz, x1.6; three accented 16ths at 128 BPM peak 0.57, 0.78, 0.86), `v.acid_env(decay:)` (legato MEG; exponential, curve 30 (`Notes::ACID_ENV_CURVE`), times ×2.6 a linear fall's with the same half-way point (`ACID_ENV_TIME_SCALE`; user's pick 2026-10-10, "the longer multiple for equal half works better for these short notes"): decay 1.56 s, accents 0.52 s (0.6/0.2 linear); `curve: :linear, decay: 0.6, accent_decay: 0.2` is the earlier MEG; `acid_voice(env_curve:)` the same; A/B in /app/tmp/listening/omnibus2/).  Demo voice `bin/synths/acid.rb` (`acid_voice(clip_or_midi, ..., env_curve:)`, a one-voice Synth), song `bin/songs/acid_song.rb`.  Diode accuracy (2026-10-10, study on branch `research-acid-diode`): our equal-capacitor ladder is within 0.7 dB of Stinchcombe's TB-303 core (bottom capacitor halved) at the same knob; the 303's feedback coupling capacitors (~10 Hz) only change the subsonic band (< 0.5 dB at 55 Hz); per-stage diode saturation not built (~2x the diode's cost, a user decision).

`swap :bass, bass2` (`Session#swap`, `lib/mb/sound/session/clip_swaps.rb`) changes a player's clips on the next bar via `ClipSource#swap_clip` on every ClipSource in the graph (exact time; graph and effect state kept; sounding notes get note-offs, held values chase the new clip).  Transformed clips remember their `source` and transform (`Clip#lineage` / `#rederive`), so clips derived from the old one (`bass.transpose(12)`) are rebuilt from the new one, and a `clip.synth` follows through its one source; pass `old => new` pairs (or `kit => kit2` for `grid` rows) when a player has unrelated clips.  See `bin/songs/swap_song.rb`.

Clip feel, chance, and generators (`sequence/clip_feel.rb`, `sequence/generators.rb`; clips move notes both ways, live streams only delay): `humanize(1.n64, velocity: 0.2, seed: clip seed, vary:)`, `quantize(16, amount:, ends:)`, `swing(0.58, 16)` (a time warp per pair of steps), `chance(p)` (alias `maybe`) and `every(n, from: 1)` (Elektron-style cycle conditions, `Event#condition`; also step marks `E4.every(2, from: 2)`, `G4.maybe(0.5)`, and on Seqs; `Clip#plays?` decides both per cycle).  `Clip::Variation`s (`#variations`, `#events_for(cycle)`) change a loop every cycle repeatably from seed + cycle (starts relative to the cycle, up to a cycle outside it: an early note plays at the end of the previous cycle, cycle 0's and a launched/seeked/swapped-to cycle's early notes at the read start, `Clip#edges(early:)`; loops are humanized this way, `vary: false` too, so downbeats nudged early play exactly once; 2026-10-10: wrapping within the cycle lost or doubled them): `permute(vary: true)`, `humanize(vary: true)`, `melody(vary: true)`; mapping transforms keep them, `#repeat` unrolls them (and conditions) per copy, `|`/`&` take cycle 0.  `bake(fx or block, cycles: 1)` runs MIDI stream transforms offline into a Clip (loops bake their steady state, so echoes wrap; `cycles:` keeps several cycles of a varying loop; code note: may change with library/live work).  Generators: `euclid(hits, steps, note = kick, step: 16, rotate:, velocity:)` (Bjorklund, a Seq) and `melody(scale, count, step:, rhythm: clip, leap: 3, range:, weights:, rest:, seed: (drawn from MB::Sound), vary:)` (a weighted walk over scale degrees).
