# Sequences

Detailed notes moved from CLAUDE.md (2026-10-10); CLAUDE.md keeps a summary and points here.  Update both when behavior changes.


`lib/mb/sound/sequence/` (`MB::Sound::Sequence`) holds musical sequences: immutable `Clip`s of `Event`s timed in exact Rational whole notes, built with `seq` (e.g. `seq(C4, E4, G4.n4).n8`), `grid` (drum step strings like `'x...x...'`), and note length methods on `Note` (`n1`-`n8`, `n12`-`n128`, `.d`, `.t`, long names).  A clip is just a MIDI source: `clip.stream` is a `MIDI::Stream` of a new `MIDI::ClipSource` (a `TimelineNode`; a new source per call, since each follows its own graph's timeline), and its node methods are the mono (last-note) `Notes` nodes of `clip.notes`: `clip.env`/`amp_env`/`fm_env`/`filt_env` (NoteEnvelopes: `:analog` curves, default 5 ms/0.2/0.7/0.3, Envelope keywords such as `curve:`/`sensitivity:` (velocity range; `velocity:` is the input), GM2 time scaling off unless `gm: true`), `clip.tone`/`hz` (a key-synced NotePitch: `clip.tone.ramp`, `.transpose(7)`), `clip.freq` (Hz node), `clip.period`, `clip.gate`, `clip.trigger`, `clip.number`, `clip.velocity(range:)`; each call makes its own Notes, so share one with `n = clip.notes`.  Edges land on exact samples at the tempo of a shared `Transport` (`bpm 120`); `spec/test_data/clip_node_reference.json` (outputs of the removed `ClipNode` renderers) is the edge reference.  `clip.synth(voices: 2, **synth_options) { |v, i| }` is `Synth.new(clip, voices:, tail: 0)` (`v` is a lane's Notes; returns Channels for multichannel voices).  Non-looping clips end one buffer after their last note-off; NoteEnvelopes end once their stream ended and they are idle; an ended reset input (key sync trigger) only stops resets, so tones ring through releases.  `legato(0.85)` shortens notes without changing the rhythm.  `reverse` (alias `retrograde`) mirrors a clip or reverses a Seq's steps; `permute([2, 0, 1])` / `permute(seed: 3)` (alias `shuffle`) moves notes among the same rhythm, repeatably from the clip's seed.  In a `Session`, looping clips play in phase with the transport timeline (`seek`, `rewind`), so graphs started at different times stay in sync.  `clip.loop(align: :launch)` (`Clip#launch_aligned?`) instead counts cycles from the exact launch time (`Player#launch`, the bar line rather than the floored first sample; `TimelineNode#start_at(launch:)`), or from the swap that brings it in; seeks and rewinds keep that anchor (the loop plays as the timeline loop rotated by the launch time; before the anchor it plays the cycles leading up to it), only a new launch (`bg`, `resume`) moves it, and `:clip` launch points ignore such loops.  `rotate(amount)` moves a clip's events later by a Duration (or signed whole notes), wrapping within its length.  See `bin/songs/sequence_demo.rb`.  Launches, replacements, swaps, and master chain switches land on the sample whose window holds their time (floor, like Notes edges), so a clip launched on a bar line between samples (e.g. 112 BPM) keeps its first note. See `bin/songs/sequence_demo.rb`.

Note marks (`Sequence::NoteMarks` on Note, the same methods on `Seq::Step`, each returning a Step, chaining in any order: `~!A1`, `A1.!.~`, `(!A1).up.n8`): flam `D2.flam` / `.flam(25.ms)` (grid 'f'/'F'; drum kits play a grace stroke then the hit; see drums.md), accent `!A1`/`.accent`/`.acc`/`.a!` (Step flag `accented`, velocity `Clip::ACCENT_VELOCITY` 1.0 vs default 0.75; grid `X` sets it too), slide `~A1`/`.slide(overlap)`/`.s!` (flag `slid`; the note sounds `Seq::SLIDE_LEGATO` 1.02 of its last step, overlapping the next so mono voices glide and legato envelopes hold; `legato` transforms leave slides alone), octaves `up(n)`/`dn(n)` (alias `down`)/`oct(n)` defined once on Pitch via `transpose` (also on Steps and Seqs).  `!` is overridden only on Note and Step (audit and guard: `spec/lib/mb/sound/note_negation_spec.rb`; test values that may be Notes with `nil?`, never `!x`); `!A1.n8` is `!(A1.n8)` (seq raises with a hint); `!~A1` is Ruby's not-match operator (write `~!A1`); `-A1`/`+A1` stay undefined (minus is for signal inversion).  `Rest`/`R` (a rest Step) and `Tie`/`T` (holds the previous note one more step, resolved when the Seq builds events; a rest after a rest or at the start; grid `-`).  `Seq#acid(accent: 1.0, normal: 0.6, gate: 0.5, slide: 1.02)` plays a Seq like the 303's sequencer (half-step gates, ties hold, slides overlap, accent/normal velocities; tracked for swaps); `acid(*items, step: 16)` is `seq(...).len(step).acid`.  `Seq#loop` returns a looping Seq, so step transforms (`acid`, `acc`, `len`, ...) work on loops.  Voice helpers: `v.accent(0.8)` (0/1 per note from velocity), `v.accent_sweep(env, resonance:)` (the 303's accent capacitor: lowpass at 2 - 0.8 r Hz, x1.6; three accented 16ths at 128 BPM peak 0.57, 0.78, 0.86), `v.acid_env(decay:)` (legato MEG; exponential, curve 30 (`Notes::ACID_ENV_CURVE`), times ×2.6 a linear fall's with the same half-way point (`ACID_ENV_TIME_SCALE`; user's pick 2026-10-10, "the longer multiple for equal half works better for these short notes"): decay 1.56 s, accents 0.52 s (0.6/0.2 linear); `curve: :linear, decay: 0.6, accent_decay: 0.2` is the earlier MEG; `acid_voice(env_curve:)` the same; A/B in /app/tmp/listening/omnibus2/).  Demo voice `bin/synths/acid.rb` (`acid_voice(clip_or_midi, ..., env_curve:)`, a one-voice Synth), song `bin/songs/acid_song.rb`.  Diode accuracy (2026-10-10, study on branch `research-acid-diode`): our equal-capacitor ladder is within 0.7 dB of Stinchcombe's TB-303 core (bottom capacitor halved) at the same knob; the 303's feedback coupling capacitors (~10 Hz) only change the subsonic band (< 0.5 dB at 55 Hz); per-stage diode saturation not built (~2x the diode's cost, a user decision).

`swap :bass, bass2` (`Session#swap`, `lib/mb/sound/session/clip_swaps.rb`) changes a player's clips on the next bar via `ClipSource#swap_clip` on every ClipSource in the graph (exact time; graph and effect state kept; sounding notes get note-offs, held values chase the new clip).  Swaps wait in the Session's change queue and are worked out from the clips playing when they land, so several swaps for one player at different times all happen (a ClipSource holds one pending swap; before 2026-10-10 the later swap silently replaced an earlier queued one); errors that are clear when the swap is made still raise then.  Transformed clips remember their `source` and transform (`Clip#lineage` / `#rederive`), so clips derived from the old one (`bass.transpose(12)`) are rebuilt from the new one, and a `clip.synth` follows through its one source; pass `old => new` pairs (or `kit => kit2` for `grid` rows) when a player has unrelated clips.  See `bin/songs/swap_song.rb`.

Clip feel, chance, and generators (`sequence/clip_feel.rb`, `sequence/generators.rb`; clips move notes both ways, live streams only delay): `humanize(1.n64, velocity: 0.2, seed: clip seed, vary:)`, `quantize(16, amount:, ends:, window:)`, `swing(0.58, 16)` (a time warp per pair of steps), `chance(p)` (alias `maybe`) and `every(n, from: 1)` (Elektron-style cycle conditions, `Event#condition`; also step marks `E4.every(2, from: 2)`, `G4.maybe(0.5)`, and on Seqs; `Clip#plays?` decides both per cycle).  Fill marks (Elektron's FILL condition, 2026-10-10, `arrangement.md`): `E4.fill`, `E4.fill(:big)`, `.nofill(name = nil)` on Notes and Steps, `Seq#fill`/`#nofill`, `Clip#fill` with no argument or a Symbol (`fill(span)` still repeats to fill a span), `Clip#nofill`, `Kit#fill(name, rows or a block returning a Kit)` (layers fill rows onto rows of the same name, looping again), `Kit#nofill(*rows, name:)`; stored as `Event#fill_mark`/`Step#fill_mark` (`[:fill or :nofill, name]`; a Struct member named `fill` would be shadowed by the mark methods).  Marked notes play by the transport's `FillMap` (set by a playing song form) at their note-on (`Clip#edges(fills:)`); without a form, fill notes never play and nofill notes always do.  `Clip::Variation`s (`#variations`, `#events_for(cycle)`) change a loop every cycle repeatably from seed + cycle (starts relative to the cycle, up to a cycle outside it: an early note plays at the end of the previous cycle, cycle 0's and a launched/seeked/swapped-to cycle's early notes at the read start, `Clip#edges(early:)`; loops are humanized this way, `vary: false` too, so downbeats nudged early play exactly once; 2026-10-10: wrapping within the cycle lost or doubled them): `permute(vary: true)`, `humanize(vary: true)`, `melody(vary: true)`; mapping transforms keep them, `#repeat` unrolls them (and conditions) per copy, `|`/`&` take cycle 0.  `bake(fx or block, cycles: 1)` runs MIDI stream transforms offline into a Clip (loops bake their steady state, so echoes wrap; `cycles:` keeps several cycles of a varying loop; code note: may change with library/live work).  Generators: `euclid(hits, steps, note = kick, step: 16, rotate:, velocity:)` (Bjorklund, a Seq) and `melody(scale, count, step:, rhythm: clip, leap: 3, range:, weights:, rest:, seed: (drawn from MB::Sound), vary:)` (a weighted walk over scale degrees).

Ghost chords (`sequence/ghost_chords.rb`, 2026-10-11, sound-design-1; from the maintainer's melody reference): `clip.ghost_chords(1, 4, 7, 6, per: 1.bar, scale: scale(:minor, :a), size: 3, harmonic: false, tie: :contour, passing: nil)` moves each note to the nearest tone (any octave) of a silent chord progression, one chord per `per` (default one bar of the transport's meter), cycling; rhythm, velocities, and marks stay.  Chords are scale degrees counted from 1 like Roman numerals (triads, or `size: 4` sevenths, from every other scale note), explicit Arrays of notes, or nil (no snapping in that span).  `scale:`/`root:` as in the MIDI transforms (a Scale, name, or offsets; default the session key's scale, `key :a, :minor`, read when the chords are built, on `root:` if given: maintainer decision 2026-10-18 in midi-consol-2b, :minor before; every repo caller already passed `scale:`, so renders are unchanged).  `harmonic: true` raises the scale's minor seventh for the chords (harmonic minor: V major, vii diminished; raises without a minor seventh).  Ties between two chord tones follow `tie:` :contour (the direction the original melody moved into the note; repeats and a non-looping clip's first note go down; a looping clip's first note compares with its last), :down, or :up.  Notes shorter than `passing:` stay as passing notes.  A looping clip repeats to the least common multiple of its length and the progression (at most `Clip::MAX_GHOST_REPEATS` = 64 copies) and keeps looping; a non-looping clip keeps its length.  Tracked as a derivation (swaps rederive it).  Streams: `Stream#ghost_chords` (midi-consol-1) counts the timeline's bars, live input included (see the consolidation notes below).  Recipes print it, and the writer now prints Scales as `scale(:minor, A4)` (loadable: `scale` is in `GraphIO::Registry::TOP_EXTRA`) and `Rest`/`Tie` steps (they printed FIXMEs before).
- Explicit events (graph-io-3): `events([0r, 1r/8, 57, 0.75], [1r/4, 1r/8, 60, 1.0, { accented: true }], length: 1r/2, loop: true)` (`SequenceMethods#events`) makes a clip of rows `[start, length, value, velocity, { marks }]`; graph documents and `to_ruby` print clips without a recipe (captures, `Clip.new`) this way (graph_io.md).

Clip and stream consolidation (midi-consol-1, 2026-10-16; maintainer decisions 1-7 of that day): "shared core, two front ends".
- Half and double time (omnibus8, 2026-10-17; panel Kez #16, help H3): `clip.halftime(factor = 2)` / `doubletime(factor = 2)` (aliases `half_time`, `double_time`) are `stretch(factor)` / `stretch(1 / factor)`: every start, length, and the clip (loop) length, exact Rationals; looping clips keep looping and their alignment, so a half-time loop is as long as the stretched clip and follows the timeline on exact samples across loop edges.  Also on Seqs (kept as Seqs, through `Seq#stretch`) and grid Kits (`Kit#stretch`/`#halftime`/`#doubletime`, every row).  They live with `stretch` on Clip rather than in `Sequence::Feel` (they map times uniformly; no per-note draws).  No stream version: slowing or speeding a live stream needs delaying or anticipating its input (maintainer 2026-10-17: not now; maybe some day as a MIDI looper or delay-buffer playback-rate feature; listed in midi.md's not-built list).  Specs: `spec/lib/mb/sound/sequence/halftime_spec.rb`.
- One event-level core per concept, `Sequence::Feel` (`sequence/feel.rb`): `humanize_draw` (two draws per note, timing then velocity), `quantize_step` (`:nearest` for clips, `:next` for streams, `window:`), `swing_warp`, `condition_plays?`, and the defaults `HUMANIZE_TIME` (4 ms), `SWING` (0.58), `GRID` (16).  Clip methods and stream transforms take the same option names: `humanize(time, velocity:, seed:)` (clips also `vary:`; live notes have no cycles), `quantize(grid, amount:, ends:, window:)`, `swing(amount, grid)` (streams from 0.5: they only delay), `transpose(step, scale:, root:)`, `ratchet(count, rate:, velocity:)`, `chance(p)`/`maybe`, `every(n, from:)`, `legato`, `ghost_chords(...)`.  Results of existing calls are unchanged (same arithmetic in the same order; every song and synth render md5-identical).
- Clips may move notes earlier and wrap in loops; streams only delay, so: stream `legato` of 1 or more delays note-offs, below 1 it shortens notes that carry a length hint (`MIDI::Event#length_hint`, round 2 below; a length gives `note_length`), stream `ratchet` needs `rate:` (hits while held, the last ending with the key; clips split the note evenly without one), stream `every` counts bars of the timeline (meter map) where clips count loop cycles, stream `chance` decides per note (seed + counter) where clips decide per cycle and note, stream `ghost_chords` counts chords from the timeline's bars (or `per:` from timeline 0, so timeline-aligned loops get the clip's chords) and has no `passing:`; it works on live input too (round 2: the maintainer lifted decision 3's `live_error`, since the stream follows the timeline's bars).  Equivalence specs (`spec/lib/mb/sound/midi/transform/clip_ops_spec.rb`): a clip baked through the stream op equals the clip op for swing, ratchet with a rate, legato, ghost chords, and scale transposes.
- Transpose (decision 2): `Clip#transpose`/`Seq#transpose(step, scale:, root:)` move by scale degrees (`Transform::Steps`, `Steps#apply_value` keeps Notes as Notes); the default chromatic scale runs the old code, Intervals stay semitones, Arrays add up; pitch-marked sampler hits move their mark by semitones (other scales raise).
- `Transform::Spec` chains carry the clip operations (decision 3): `Stream::TRANSFORMS` lists them, so Notes mirrors them and graph documents load them; a chain must still start with a top-level builder (`echo`, `arp`, `strum`, `chord`) to print as Ruby.
- Length hints (round 2, maintainer 2026-10-16: "length hints, else pass + live_error"): sources and transforms that know a note's length at its note-on put it on the note-on as `Event#length_hint` (in-process only; MIDI bytes unchanged): clip sources (a `Duration` from the note-on to the note's end, so it follows tempo changes), the arpeggiator (gate length), gated echoes, ratchet hits, `note_length`, and `legato` (scaled); `with_note`/`at` copy it (chords, ungated echoes, transpose, humanize, which shifts note-offs with note-ons), and NoteMap transforms that move note-offs (`quantize(ends:)`, `swing`) recompute it through `note_off_time`.  `Stream#legato` below 1 plans the note-off at the note-on from the hint (no added latency): a re-strike keeps the new note (the ledger drops the old planned note-off), an earlier played note-off still ends the note, planned note-offs go out after the stream ends and ring on through `:ring` jumps.  Notes without a hint pass through unchanged after one `live_error` (an error in scripts and specs).
- Naming (decision 6, aliases only): `Clip#shift` = `#rotate` (wrapping), `Stream#rotate` = `#shift` (delay); `Clip#legato`/`Seq#legato` take a length for fixed lengths (new `Clip#note_length`; `Seq#len` stays the step length setter, so clips have no `len`), `Stream#legato` a fraction (1 or more) or a length.  Degree bases: Scale methods count from 0, `ghost_chords` from 1 (Roman numerals), transform steps are relative moves (0 = the same note); top-level `chord(:min7, root: :d)` is a chord value, every other `chord(...)` the transform.
- Generators (decision 5): `Clip#map_cycles` applies list transforms to every generated cycle (`Producer#cycle_mapped`), so `ratchet`, `roll`, `truncate`, `permute` (seeded per cycle; explicit orders raise), and `ghost_chords` (each cycle at its place in the progression, contour from the previous cycle) work per cycle like the `map_clip` transforms; `bake` still bakes N cycles.

## Clips that remember their instrument (play-1, 2026-10-17)

Maintainer, 2026-10-17, after `bg @l_amen` (lesson :chop's chop clip) raised "Cannot play ... Seq in the background": "Unexpected but not sure what the right thing should be"; decided: clips remember the instrument they came from, so `bg :x, chop` / `play chop` equal `chop.sampler(slices)`; plain clips play the soft default patch.

- `Sequence::PlayedBy` (`lib/mb/sound/sequence/played_by.rb`, in Clip and grid Kit): `#instrument` (nil by default; `@instrument` is set to nil in both initializers so every clip has the same ivar shape) and `#played_by(inst)`, a copy that plays on `inst`: anything with `#sampler` (Instrument, Slices, Sample, SF2 font) for clips, a drum machine with `#kit` (`Drums::TR808`, `Drums::TR909`, `kit { }` designs) for clips and grids; nil clears it.  `Sample::Slices#chop` marks its clip with the slices (or `keymap(from:, spread:)` when those aren't the defaults), `Drums::Machine#grid` its grid with the machine.
- Carrying: `PlayedBy.carry!(klass)` (run for Clip, Seq, and Kit in `lib/mb/sound.rb` after everything that adds clip methods loads, before the recipe recorders) prepends a wrapper to every public method except readers, predicates, setters, `to_*`, and `SKIP`: a Clip or Kit result without an instrument, from a receiver with one, comes back as `result.played_by(instrument)` (a copy; nothing is mutated, so a shared clip like `source` never changes).  So `chop.loop.transpose(3).swing(0.2).humanize(...)`, `|`, `&`, `n8`, ... keep it, and new transforms do too without a list.  Methods that return other things (nodes, Notes, Arrays) pass through.
- `Playable.graph` plays a clip on its instrument (`clip.sampler(inst)`, or `inst.kit(clip)` for drum machines) and a grid on `inst.kit(grid)`, else the default patch / `tr808`; spec'd equal sample for sample in a headless Session (`playable_spec.rb`, including the lesson's `@l_amen`).
- Graph documents: chop clips print through their recipe (`brk.chop(...)`), which marks them again on load; `played_by(...)` is a recorded Clip method, printed as written; clips saved as `events(...)` rows don't keep the instrument (an Instrument built region by region already prints as a FIXME).

## Moving parameters in clip operations (midi-consol-2)

`humanize`, `quantize(amount:)`, `swing`, `chance`, `every`, and `transpose` take MIDI::Params (knobs, `cc(...)`, tempo LFOs, clips, arithmetic; see midi.md "Parameters that move"): a param adds a Variation reading at each event's clip position when a cycle's events are made (`every` at the cycle's start), so every cycle reads anew; plain values take the original code (bit-identical).  `Clip::ParamOperations` is prepended to Clip and Seq (Seq's own transpose/chance/every too; a param result is a Clip), passing arguments through as given so recipes print the call as written.  Lengths from params are seconds when plain numbers.  `Clip#value_at(pos)` makes a clip a param itself (`transpose(seq(0, 5, -2, 3).n1.loop)`).  Scale defaults: `scale(:dorian)` without a root takes the session key's root (C until `key` changes it), and `snap`/`degrees`/`lock` without a scale follow the session key at each note; `ghost_chords` without a scale builds its chords in the session key's scale (midi-consol-2b, 2026-10-18).
