# Drum machines

Detailed notes moved from CLAUDE.md (2026-10-10); CLAUDE.md keeps a summary and points here.  Update both when behavior changes.


`tr808(source, **knobs)` (`DrumMethods`, `Drums::TR808.kit`; `lib/mb/sound/drums.rb`, `drums/`) is a TR-808-flavored kit, not an exact emulation: a `Drums::Kit` mixing `Drums::Voice`s (kick, snare, rimshot, clap, closed/open hat, cymbal, cowbell, toms, congas, claves, maracas; `kit[:kick]`, `kit.voices`) built from `trigger.ping(freq, decay:)` resonators (`GraphNode::Resonator`, kernel `FastResonator.ping`: a complex one-pole whose frequency moves without changing the ring level), naive-square metal banks (shared by the hats and cymbal), and noise.  Sources: a grid `Sequence::Kit` (rows name voices, aliases, or GM drums), or any MIDI source (clip, `midi`, file, Stream) routed by `TR808::GM_MAP`; knobs per voice as Hashes (`kick: { tune: 45, decay: 1.2 }`; numbers, Lengths, or nodes); the open hat is choked by the closed hat; idle voices are skipped (`skip_idle:`; same samples at any buffer size since 2026-10-13: a voice falls asleep only on the `Synth::SKIP_GRID` 800-sample grid after `SLEEP_TIME` of silent grid cells and wakes on the exact hit sample, splitting buffers as needed; before, both moved with buffer edges, so metal voices and noise differed at 367/368-sample buffers).  What a sleeping voice still reads (`Voice#boundary`: its branches of Tees read elsewhere, e.g. the shared metal bank, and its Notes nodes) is decided when it skips, cached on `Tee.branch_changes` (fixes-9, 2026-10-13: it was fixed at the first buffer, so a reader made later fell behind the voice and waking raised `BranchBufferOverflow`); branches made while building the voice's graph and read by nothing in it (`TR808.voice` wraps the build in `Tee.collect_branches` and passes `built:`) don't count, like Synth lanes since fixes-8.  The metal bank's naive squares at 540 and 800 Hz have jumps exactly on samples, which used to land a sample apart by block size; naive shapes now snap onto jumps within 1e-9 cycles (see oscillators).  A grid kit with an open hat and no closed hat used to raise (the grid's source Hash created empty entries; fixed 2026-10-13).  A `Resonator` whose input has ended now stops on the exact sample where its ring falls below -120 dB (binary search over kernel runs in the last buffer; it used to end at the first buffer start below -120 dB, so a sum of pings, which ends with its first input, cut off at buffer-dependent times: the zen persona's gong, 2026-10-13).  Still per buffer: a voice played by a finite source ends after `QUIET_TIME` below -90 dB counted in whole buffers, so the last sub -90 dB samples can differ by buffer size; likewise a Notes trigger or gate node ends (returns nil) at the first buffer after its finite source ends.  Randomness (noise): `seed:` (default drawn from MB::Sound.seed); voice i in `VOICES` order is built in `MB::Sound.with_seed(seed + 1 + i)` (2026-10-10, so graph-io prints one `seed:`; noise values changed from before, no A/B needed per the maintainer).  Velocity (`Drums.accented`, power curves velocity ** e): `velocity_curve: :grid` (clips, grids, trigger signals) puts x (0.75) `accent:` dB (default 6, user-confirmed) below X; `:midi` (files, live MIDI, performed clips; chosen from the source by `Drums.velocity_curve`) puts velocity 64 `accent:` dB below 127 (about linear at 6 dB; the grid curve gave -14 dB at 64).  Recording (fixes-5, 2026-10-13): clips recorded from live input are `Clip#performed?`, so a recorded drum loop plays with the monitor's :midi curve (it came back up to 6 dB softer through :grid), and a kit built for a performed clip (the recording's empty placeholder) has every voice of the map; `Kit#plays_clip?` tells Arrangement tracks to build the patch again rather than swap in a clip the kit wasn't built for (other voices or another curve).  Armed tr808 tracks monitor live input (`LiveClip#to_midi_stream`).  `more_cowbell: true | dB` raises the cowbell's level and its decay × 2^(dB/12).  `outputs: :separate` (alias `:individual`) returns a `GraphNode::Channels` of the voices, named and in `VOICES` order (`outs[:snare]`, `outs.names`; channels may have names in general, kept through per-channel DSL calls), adding up bit for bit to the mix.  Defaults from listening (user, 2026-10-08): snare heads 0.25 s with snappy 0.3 (round 2's louder, longer noise at 0.6 was too noisy), cowbell 0.42 s.  Demo `bin/songs/drums_808.rb`, MIDI script `bin/synths/drums_808.rb`; renders `/app/tmp/listening/drums_808/` (`round2/`).  Not yet: a melodic kick voice, a 909, per-voice pan.

## Kit builder and TR-909 (drums-2, 2026-10-13)

Stage 2 of "Sampler + second drum machine" (maintainer: "Modular and 909").  Files: `lib/mb/sound/drums/machine.rb` (Drums::Machine, Builder), `hit.rb` (Drums::Hit), `nodes.rb` (Repeats, ChokeGate), `tr909.rb`; `DrumMethods#kit` (alias `drum_kit`) and `#tr909`.

- **Designs are values.** `kit { ... }` makes a `Drums::Machine` (voices in definition order, chokes, aliases, GM notes); `kit(source) { ... }` / `machine.kit(source, **opts)` / `machine.(source)` build a `Drums::Kit` of `Drums::Voice`s exactly as tr808 does (same Voice, Tap, idle skipping, `outputs: :separate`, `plays_clip?` notes and curve), so arrangement tracks, recording, and swaps treat a custom kit like an 808.  TR909 is a Machine defined with the same builder (dogfooding); `TR808.machine` wraps `TR808::Build` for borrowing (`tr808 :cowbell` in a kit block; tr808 itself is unchanged: shared metal banks, more_cowbell, its own seeds).
- **Voice blocks** get a `Drums::Hit`: the accented trigger (`t`), one reader per knob (defined as singleton methods, so typos are NoMethodErrors with did_you_mean; knob names that are Hit methods are refused), and layers played by the trigger at the hit's velocity: `body`/`ping` (resonator with `sweep:` and `drop:` pitch envelopes), `noise` (filters + decay env), `click`, `metal` (808 square bank), `sample` (a Sample through SamplerVoice; tune in semitones, a node goes in as `freq:` relative to the root's equal-tempered Hz), `fm` (two operators reset by the hit, `index_decay:`), `bursts` (Repeats), `env`, `sweep`, `velocity` (sample-and-hold of the trigger).  A block without parameters runs on the Hit (instance_exec), with one gets it as `h`; the kit block likewise for the Builder.  Every voice has a `level` knob applied after its block, and takes `accent:`, `velocity_curve:`, `flam:` in its knob Hash.  `voice :name, sample` makes a sample voice (knobs tune, decay).
- **Routing**: grid rows by voice name, alias (`as:`), or GM drum name; MIDI by `gm:` notes (default: the GM note of the voice's name; custom names have none unless given, and `machine.grid(16, zap: '...')` builds grids naming custom voices, since `grid` itself needs GM names or `map:`).  `hh:` is now a grid alias of the closed hat.
- **Chokes**: `choke :a, :b, :c` (each cuts off the others) or `choke :open_hat, by: :closed_hat`.  Implemented as a `ChokeGate` multiplying the voice's output (3 ms linear ramp like Envelope's choke, back to 1 at the voice's own hit; a hit beats a choke on the same sample), so any layer (rings, samples) chokes; the choker's notes are read by the voice's second input as in tr808.
- **Shuffle and flams**: `shuffle:` 0..6 delays every second 16th by n/48 beat (2n ticks of 96 PPQN; 4 is the triplet feel 2/3), or a Float swing amount, through `Clip#swing` on grid rows and clips (other sources raise).  Flams are a note mark (round 2, maintainer's choice; round 1's `flams:` second source is gone, no alias): `D2.flam`, `D2.flam(25.ms)`, `step.flam`, grid characters 'f' (flam) and 'F' (accented flam).  The mark is a field of `Seq::Step`, `Sequence::Event` (`events(..., { flam: true | seconds })`, `to_s` ' flam'/' flam20ms'), and `MIDI::Event#flam` (ClipSource passes it like pitch marks); `Notes#flam_mark` holds it per note-on (0, seconds, or -1 for true).  As MIDI 1.0 bytes a flam-marked note-on is the plain note-on: MIDI has no per-note flam, so outside gear hears one hit and .mid files don't keep flams.  Kits (Machine and tr808) wrap a voice's trigger in `Drums::Flams` when the source has any flam mark (`Drums.flams?`, static over clips, grids, and Notes/Streams reading them; live input and files never): the hit's sample gets a grace stroke (GRACE 0.6 of the velocity, before the accent curve, so -12.6 dB at the default 6 dB accent), and the hit lands the mark's time (or the kit's `flam:`, 16 ms (round 2; 18 before), or a voice's `flam:` knob) later, on exact samples at any buffer size.  Flams sits in the voice's first input, so a sleeping voice wakes on the second stroke; it alternates two output buffers (a Tap's Tee branches share them).  `Kit#plays_clip?` refuses a clip with flams for a kit built without them, so arrangement swaps rebuild the patch.  Other voices ignore flam marks.  Note: NoteNodes of one Notes must be read trigger first (reading `flam_mark` before `trigger` in a test shifted the trigger by a buffer; Flams reads the trigger first).
- **Idle skipping**: a voice also stays awake while any SamplerVoice or Repeats in its graph isn't idle (a reversed sample's quiet start, a burst more than SLEEP_TIME after the hit used to be skipped; found with the kit-builder demo's reversed swell).  Output is the same at any buffer size (specs at 7/64/367/800/2048).
- **TR-909 voices**: kick = ping with a fast sweep (punch × 5 over 18 ms) and a slower 25% drop, driven into a softclip, plus a click and a 6 ms noise tick (attack); snare = two swept heads (f, 1.62 f) and noise (snappy level and length, tone opens the lowpass); clap = four bursts 8.5 ms apart (Repeats, falloff 0.85) and a tail; toms = swept pings with a droop and a noise breath; rimshot = three pings highpassed and clipped.  Hats, crash, ride: `TR909.rom(name)`, synthesized at first use (0.15 s for all four, cached per process with a Mutex): the product of two square banks (METAL_A × METAL_B, ring modulation for density) mixed with seeded noise (ROM_SEED, so the same "ROM" every time), double highpassed, a fast + slow decay, bell partials for the ride, then `Sample::Lofi` hold at 32 kHz and 6 bits of full scale; played by the sampler with decay envelopes and tune (semitones).  No recorded cymbals anywhere.
- **Graph documents**: `tr909(...)` prints as its call.  Kit blocks print as their source (runtime blocks to the recorder, so locals from outside print FIXMEs, as for other runtime blocks), and load without trust: the loader treats `kit`, `drum_kit`, and `voice` as build blocks; a build proc run with instance_exec gives its Scope an implicit self (`Scope#implicit_self`), where receiverless calls go first; Registry::VALUES allows Builder (voice, choke, tr808, tr909) and Hit methods, plus each hit's knob names; `bursts` counts against the copies limit.
- **Plan layer**: voices stay unplanned like tr808's (Voice reads Taps itself; SamplerVoice is a plan boundary).  Not attempted.
- **Measured** (AMD 7950X, Ruby without YJIT; an 11-voice 909 grid kit, every voice playing, table builds included): 2 s rendered in 0.22 s at 128-sample buffers (11% of realtime) and 0.05 s at 800 (2.7%).
- Demos: `bin/songs/drums_909.rb` (house into techno, shuffle and a flammed roll), `bin/synths/drums_909.rb` (MIDI, CC 16-19), `bin/songs/kit_builder.rb` (the junkyard kit: scratch kick, FM can, a log drum whose tune knob plays a melody, a reversed bounced swell, borrowed 909 clap and 808 cowbell); renders in `/app/tmp/listening/drums-2/`.
- **Round 2 (maintainer's Bench picks, 2026-10-13)**: kick defaults punch 0.9, drive 0.8, attack 0.8 (was 0.6, 0.4, 0.5); hats tune -3 semitones and short (closed decay 0.06, open 0.3; was 0 and 0.16 / 0.9); flam spacing 16 ms (DEFAULT_FLAM, was 18); the snare unchanged; toms reworked after the 808's were preferred: tunes 100/145/200 Hz, decays 1.1/0.95/0.8 s (was 95/135/190, 0.55/0.5/0.45), a gentle strike (sweep 0.3 over 20 ms, was 0.9 over 10 ms) and a long 35% glide over 0.35 s, a soft clip for roundness, a darker noise breath (bandpass 3x the pitch, was 5x).  The machine default stays straight (shuffle nil); the house template plays shuffle 2.  New demo `bin/songs/even_more_cowbell.rb` (`MB::Sound.cowbell_kit`: the scratch kick and snare, the 808 cowbell tuned by a clip, an FM bell, a bounced 808 cowbell crushed with `lofi(:sp1200)` played an octave down, and `fever`, one knob for level and ring).  The 909 cymbals render bit-identically after sampler-2 (b766c403: per-sample reads; the hits pass `interpolation: :optimal` and the ROM samples keep the default read).
